# 前端效果图鉴 · Frontend Effects Index

一个单文件、离线的**前端效果参考墙**：17 个经典视觉效果，每张卡片里是**真实运行的效果**，点开才知道它叫什么、还叫什么俗名，并给出**一句能直接说给 AI 听的话**和**一段能照抄的代码**。

> 解决的问题：AI 写代码时后端清晰、前端说不清。"那种亮亮的、会飘的东西"这类描述交给这个页面——你只需要指认。

## 打开

双击 `index.html`。零依赖、无构建、不需要服务器，浏览器直接打开即可（`file://` 可用）。

## 怎么用

| 操作 | 说明 |
| --- | --- |
| 点卡片 | 弹出详情：中文名、英文名、**一组俗名**、一句话描述、「复制怎么跟 AI 说」、「复制代码」 |
| 筛选 | 按 质感 / 动效 / 文字 / 布局 / 背景 分类 |
| 搜索 | 中文名、英文名、俗名、描述、关键词全参与匹配；**输入时自动回到「全部」**，避免和分类叠加成空结果 |
| 随便看一个 | 随机弹一个效果，用来快速回忆"我记得有个那种效果" |
| Esc / 点空白 | 关闭详情 |

搜索不讲究术语——搜「手电筒」出聚光跟随，搜「便当盒」出 Bento 网格，搜「一顿一顿」出步进动画。

## 收录的 17 个效果

- **质感**：玻璃拟态、新拟态、霓虹辉光、颗粒噪点、液态金属
- **动效**：磁吸按钮、聚光跟随、打字机、步进动画、骨架屏
- **文字**：渐变文字、空心描边字、逐字入场
- **布局**：Bento 网格、重叠错位
- **背景**：极光背景、赛博网格

## 加一个新效果

`index.html` 里三处：

1. `const D = { ... }` —— 效果的 demo HTML（`<div class="d-xxx">`），样式写进 `<style>`。
2. `const EFFECTS = [...]` —— 加一条记录：

```js
{id:'xxx', no:'018', cat:'动效', name:'中文名', en:'English Name',
 desc:'一句话说清它看起来是什么样。',
 say:'直接说给 AI 的实现口径：用什么技术、关键的 CSS/JS 在哪。',
 keys:'检索关键词 空格分隔',
 demo:D.xxx}
```

3. `AKA`（俗名，参与搜索与展示）和 `CODE`（照抄可用的代码）各加一条，键名用同一 `id`。

`no` 递增、`cat` 用已有分类即可；卡片、筛选、搜索、详情、复制全部自动生成。

## 已知边界

- 单文件、无构建，刻意不做组件化——它的用途是"看一眼、对一下名字"，不是生产组件库。
- 磁吸按钮 / 聚光跟随依赖鼠标移动，触屏上只呈现静止态。
- 复制在 `file://` 下走 `execCommand`（Chrome 实测可用）；若被浏览器策略拦截，按钮会明说"复制失败"。
- 详情浮层里的代码是**核心片段**，不是完整组件；直接贴进项目时留意各自的容器尺寸。
